YouTube creators obsess over title style: capitalization, length, punctuation.
The reason for this is believing it drives performance. I wanted to test this
properly: does title style predict how well a video performs relative to its
channel's subscriber count, in a way that is generalizable to almost all major
channels across YouTube.

The code that I used to run this is not here because most of it involves my own personal YouTube API v3 key, and I cannot have that be public for obvious reasons.
